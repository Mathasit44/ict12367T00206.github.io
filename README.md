# 🛒 Online Store Website

เว็บไซต์ขายของออนไลน์ ที่พัฒนาโดยใช้ **Django**, **HTML/CSS/JavaScript** พร้อมระบบจัดการสินค้า ตะกร้าสินค้า และการสั่งซื้อ

## 📌 Features

- 🔍 ค้นหาสินค้าและเรียกดูหมวดหมู่
- 🛒 เพิ่ม/ลบสินค้าในตะกร้าสินค้า
- 🧾 จัดการคำสั่งซื้อ และรายละเอียดการชำระเงิน
- 👤 ระบบล็อกอิน/สมัครสมาชิก (User Authentication)
- 🛍️ แอดมินจัดการสินค้าและคำสั่งซื้อได้
- 📱 รองรับการใช้งานบนมือถือ (Responsive Design)

## 🚀 Tech Stack

- Backend: Django (Python)
- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Database: SQLite (พัฒนา) / รองรับ PostgreSQL หรือ MySQL
- Authentication: Django's built-in Auth
